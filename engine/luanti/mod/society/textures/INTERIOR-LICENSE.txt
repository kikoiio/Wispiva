Reproduce from the repository root:
    python3 tools/generate_interior_textures.py

Textures have 64 x 64 pixel faces. The two coffee_table_paper/tea PNGs each pack
two such faces into a 64 x 128 atlas for the engine's sheet texture modifier.
Only the window texture has an alpha channel.
