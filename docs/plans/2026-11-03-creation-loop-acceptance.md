# 建造与修复闭环验收计划

计划日期：2026-11-03。完成日期：2026-11-05。此计划已归档；当前优先级由项目跟踪器维护。

## 目标与范围

从自然语言创建可检查的小场景，让程序读取已提交的最新场景、指出可确定的问题，并在安全时自动修复；保存和重载后结果一致。验收场景是紧凑木屋，用于验证回路，不是固定产品模板。

## 验收结果

| 范围 | 证据 | 结果 |
| --- | --- | --- |
| A：真实模型建造与修复回路 | [Actions run 42000591823](https://github.com/kikoiio/Wispiva/actions/runs/42000591823)；三次分别生成 139、121、121 格木屋，空间诊断均为零；注入的地板缺口由确定性修复处理，没有额外模型调用，保存重载一致 | 通过本场景的 3/3 验收 |
| B：场景视觉 | [Actions run 42000591908](https://github.com/kikoiio/Wispiva/actions/runs/42000591908) 的合成浏览器流程通过；另检查了隔离真实模型海岸场景的全景与室内视角 | 通过记录中的样本，不代表任意场景 |
| C：居民行为 | 隔离样本中单独核对了一次真实模型居民行动；另以确定性一日回放检查保存、记忆重载与地点投影。回放不代表模型连续驱动了一整天 | 通过记录中的样本，不代表长期自主运行 |
| D：规模与 soak | `npm run benchmark:voxel` 检查 756／5,000 格样本的上下文大小、存档大小和重载；[Actions run 41683058142](https://github.com/kikoiio/Wispiva/actions/runs/41683058142) 完成 7 日合成世界重启测试 | 通过记录中的样本；不测浏览器／GPU 渲染 |

历史失败按性质区分：Actions runs [41967391134](https://github.com/kikoiio/Wispiva/actions/runs/41967391134) 和 [41998490841](https://github.com/kikoiio/Wispiva/actions/runs/41998490841) 在请求到达模型服务前因配置映射或客户端问题停止，不是模型质量失败。更早的真实请求确实出现过空正文、格式错误和超时；最终 3/3 结果只适用于表中限定的模型配置和建造样例。

一次旧体验及其后续影响见[创建体验回顾](../research/2026-10-29-creation-experience.md)。

## 结论与边界

本计划范围内没有剩余实施项。建造、有限诊断、确定性局部修复、持久化和所列验收均已完成。

这些结果不覆盖任意复杂场景、其他模型或提示、长期自主行为、长期墙钟运行、大场景渲染和完整物理。它们是明确的后续范围，除非另行立项，不属于本计划的待办。
