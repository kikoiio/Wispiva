# Wispiva 原型

Wispiva 让想法形成可以观察和演化的世界。本分支用于开发和体验原型：通过对话创建小世界，建造三维场景，再观察角色行动与世界变化。

## 运行

需要 Node.js 24。在仓库根目录执行：

```bash
npm ci
node server.mjs
```

打开 [http://127.0.0.1:5175/](http://127.0.0.1:5175/)。启动和观看不会调用模型；对话、生成和角色自主行动需要按 [.env.example](.env.example) 配置模型服务。实际配置与世界存档保存在本机，不应提交到仓库。

## 体验

从一句想法或 UTF-8 文本素材开始。选择“动手建造”生成或修改场景，“自动建造并检查”最多运行 4 轮：程序先处理有精确坐标的门洞／窗户修复，再让模型读取最新场景并提出其他增量；loop 会在剩余轮数内修正可解析的格式和命令校验错误，网络失败、超时、取消或场景过期则立即停止。应用内模型请求默认有 180 秒上限；起点校验失败会显示最多三条诊断消息和路径，不显示内部细节。“先聊想法”只讨论。程序显示实际提交、无变化或失败，失败后可重试同一请求或调整原描述。支持撤销、重做与室内查看，刷新后保留进度。设定明确后查看起点草稿，检查并确认进入；运行页可以播放、暂停或单步观察。

当前适合探索小规模场景。角色知情、行动前提、资源变化和地点连接有有限规则；体素上下文与存档已有 5,000 格合成基准。合成浏览器已验收湖岸、水面、木屋、室内桌子、地点角色投影，以及全景、室内和旋转视角。当前模型曾按结构方案生成 121 格和 159 格、空间诊断为零的木屋；程序可确定性修复检查器精确定位的门洞，但重复完整建造与修复的稳定性还未通过。此前的湖边木屋样例仍留下 5 项诊断，简化样例也出现无效命令。空场景无命令不会误报完成。真实模型生成场景的视觉和持续行为、大场景渲染、长期记忆、复杂物理和平行世界仍未验证。
