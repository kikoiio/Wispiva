# Wispiva 原型

Wispiva 是一个从文字想法出发创建、观察和继续发展的世界原型。你可以描述角色、地点与事件，在三维场景中建造，并查看角色行动和世界变化。

这是用于探索创建体验的小规模原型，不代表通用模拟器。角色行动、地点和资源由有限规则处理；复杂物理、大型世界和长期自主运行尚未验证。

## 本机运行

需要 Node.js 24。在仓库根目录安装依赖并启动服务：

```bash
npm ci
node server.mjs
```

打开 [http://127.0.0.1:5175/](http://127.0.0.1:5175/)。浏览和查看已有世界不需要模型配置；对话、建造和角色行动需要配置模型服务。可从 [.env.example](.env.example) 创建本机 `.env` 并填写模型 ID、服务地址和密钥。真实密钥与世界存档不要提交到仓库。

## 创建与观察

- 用文字讨论设定，或选择实际建造；自动建造会逐轮读取最新场景并检查修改。
- 可上传 UTF-8 文本作为创作素材，也可先试用[《红发会》示例文本](examples/source-texts/sherlock-holmes/the-red-headed-league.txt)。
- 查看三维场景和空间诊断，撤销、重做或继续修复；刷新后可恢复已保存进度。
- 确认世界起点后，播放、暂停或单步查看角色行动。

本机数据保存在 `.data/prototype/`。产品目标与当前实现见[文档索引](docs/README.md)。
